PROJECT TITLE: Women Safety Web Application

DESCRIPTION:
This is a web-based women safety application developed using
HTML, CSS, JavaScript, Firebase Realtime Database, and Google Maps API.
The application allows users to register, login, and send SOS alerts
with their live location.

FEATURES:
- User Registration and Login
- SOS Alert Button
- Live Location Tracking
- Google Maps Integration
- Firebase Realtime Database Storage

TECHNOLOGIES USED:
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Realtime Database
- Google Maps JavaScript API

HOW TO RUN:
1. Open index.html in Google Chrome.
2. Register using email and password.
3. Login and go to dashboard.
4. Click SOS to send location.
5. Check Firebase Realtime Database for stored data.

NOTE:
Location permission must be allowed in the browser.
